# PocketWorker

Android-приложение для локальной работы с многорепозиторными проектами и Git без root-прав (на базе Kotlin, Jetpack Compose и Eclipse JGit).

## Основные возможности

- **Главный экран:**
  - Вкладка **«Проекты»** — список проектов-контейнеров (папок), каждый из которых объединяет несколько репозиториев (`client`, `backend`, `admin`, `services` и др.).
  - Вкладка **«Агенты»** — заготовка для будущей интеграции ИИ-агентов.
- **Экран проекта (репозитории внутри проекта):**
  - Список всех локальных репозиториев выбранного проекта с веткой, статусом изменений, счётчиками `ahead/behind`, последним коммитом и `remote` URL.
  - Кнопка **«Добавить репозиторий»** с выбором:
    - **Подключить репозиторий** — клонирование удалённого Git-репозитория по HTTPS в папку проекта (с прогресс-баром, отменой, поддержкой PAT и отображением ошибки прямо в окне без потери введённых полей).
    - **Создать репозиторий** — создание нового пустого репозитория внутри проекта (с инициализацией Git или без неё, выбором стартовой ветки, опциональным `README.md` и привязкой `remote`).
  - Поддержка трёхуровневой авторизации: токен конкретного репозитория -> общий токен проекта -> глобальный токен по умолчанию (хранение в Android Keystore AES/GCM).
- **Файлы репозитория:**
  - Навигация по папкам с хлебными крошками и поиском по файлам.
  - Отображение Git-статусов файлов (`A`, `M`, `D`, `U`), создание файлов и папок, переименование и удаление.
  - Встроенный текстовый просмотрщик и редактор файлов с нумерацией строк.
- **Система управления Git:**
  - `Stage` / `Unstage` (по отдельным файлам и массово), откат изменений, построчный просмотр `Diff`.
  - Создание коммитов (включая `Amend` и `Commit & Push`).
  - Управление локальными и удалёнными ветками (создание, переключение `checkout`, переименование, `merge`, удаление).
  - Управление удалёнными репозиториями (`remotes`: добавление, изменение URL, удаление), `Fetch`, `Pull`, `Push`, настройка имени/email автора.
- **История ветки:**
  - Выбор любой локальной или удалённой ветки для просмотра истории коммитов.
  - Просмотр деталей коммита, списка изменённых файлов, `Diff` по файлу и создание новой ветки от выбранного коммита.

## Сборка и тестирование

Требуется JDK 17 и Android SDK (Platform 35):

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```
