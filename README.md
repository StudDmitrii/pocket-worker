# PocketWorker

Android-приложение для локальной работы с Git-репозиториями без root-прав (на базе Kotlin, Jetpack Compose и Eclipse JGit).

## Основные возможности

- **Стартовый экран проектов:**
  - Список локальных проектов на устройстве с отображением текущей ветки, статуса изменений, счётчиков `ahead/behind`, последнего коммита и удалённого URL.
  - Кнопка **«Добавить проект»** с выбором:
    - **Подключить проект** — клонирование удалённого Git-репозитория по HTTPS (с прогресс-баром, отменой и поддержкой Personal Access Token).
    - **Создать проект** — создание нового пустого проекта (с инициализацией Git или без неё, выбором стартовой ветки, опциональным `README.md` и привязкой `remote`).
- **Файлы репозитория:**
  - Навигация по папкам с хлебными крошками и поиском по файлам.
  - Отображение Git-статусов файлов (`A`, `M`, `D`, `U`), создание файлов и папок, переименование и удаление.
  - Встроенный текстовый просмотрщик и редактор файлов с нумерацией строк.
- **Система управления Git:**
  - `Stage` / `Unstage` (по отдельным файлам и массово), откат изменений, построчный просмотр `Diff`.
  - Создание коммитов (включая `Amend` и `Commit & Push`).
  - Управление локальными и удалёнными ветками (создание, переключение `checkout`, переименование, `merge`, удаление).
  - Управление удалёнными репозиториями (`remotes`: добавление, изменение URL, удаление), `Fetch`, `Pull`, `Push`.
  - Зашифрованное хранение токенов доступа в Android Keystore и настройка имени/email автора коммитов.
- **История ветки:**
  - Выбор любой локальной или удалённой ветки для просмотра истории коммитов.
  - Просмотр деталей коммита, списка изменённых файлов, `Diff` по файлу и создание новой ветки от выбранного коммита.

## Сборка и тестирование

Требуется JDK 17 и Android SDK (Platform 35):

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```
